## 容器

容器是存储多个值(对象)的数据类型，如 `list`，`tuple`，`set`，`dict` 等都是容器。

由于这些**容器类**都实现了一个叫作`__contains__()`的方法，因此可以使用 `in` 或 `not in` 来判断某个 值(对象)是否存在于某个容器内。

```python
class Container():
    def __init__(self, *items):
        self.__items = items
    def __contains__(self, item):
       return item in self.__items

c = Container(*['a', 'b', 'c', 'd'])

print('a' in c) # True
print('e' in c) # False
```
