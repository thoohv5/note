## 常见错误

Bash Pitfalls 总结了日常编程中最常见的错误模式。

### 变量引用

- **变量未加引号**：`cp $file $target` 在文件名含空格时会出错，应写 `cp "$file" "$target"`
- **echo 未加引号**：`echo $foo` 会做单词拆分和通配符展开，用 `printf '%s\n' "$foo"` 更安全
- **[ 测试未加引号**：`[ -n $foo ]` 为空时返回 true，应写 `[ -n "$foo" ]`

### 循环陷阱

- **`for i in $(ls *.mp3)`**：不应用 ls 解析文件列表，直接使用 glob：`for i in *.mp3; do`
- **`for i in {1..$n}`**：大括号在变量展开前执行，应用 `for ((i=1; i<=n; i++))`
- **管道后计数器失效**：`grep foo bar | while read -r; do ((count++)); done` 中 while 运行在子 shell，变量修改不生效

### 条件判断

- **`[ $foo = "bar" ]`**：变量为空时报 `unary operator expected`
- **`[` 内不能用 `&&`**：应写 `[ a = b ] && [ c = d ]` 或 `[[ a = b && c = d ]]`
- **`[[ $foo = $bar ]]`**：右侧不加引号时是模式匹配而非字符串比较，应写 `[[ $foo = "$bar" ]]`
- **`[[ $foo =~ 'some RE' ]]`**：右侧加引号会丧失正则含义，正则放变量中

### 其他常见错误

| 错误 | 正确写法 |
|------|----------|
| `cd /foo; bar` | `cd /foo && bar` |
| `cat file \| sed 's/a/b/' > file` | `sed -i 's/a/b/' file` |
| 重定向顺序 `2>&1 >>log` | `>>log 2>&1` |
| `local varname=$(cmd)` | 分开写以获取返回码 |
| `echo "Hello!"` 报 event not found | `set +H` 或单引号 |
