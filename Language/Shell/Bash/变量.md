# 变量

```bash
1. 变量与值之间不得有空格
2. bash默认所有的变量都是字符串
3. 本地变量作用域，当前shell
4. ``或 $() 保留命令输出
5. () 开启子shell
```

### 特殊变量

| 符号 | 含义 | 应用 |
| --- | --- | --- |
| $0 | 脚本的名称 | 脚本出错，脚本帮助使用 |
| $n | 脚本参数 | 命令行传参，n≥10时，需要使用${10} |
| $# | 脚本参数个数 | 用于参数数量检查 |
| $* | 脚本所有参数 | 双引号(for)：所有参数作为一个整体，一个参数 |
| $@ | 脚本所有参数 | 双引号(for)：每个参数独立的 |
|  |  |  |
| $? | 上一条命令的返回值，0正常，非0错误 |  |
| $$ | 脚本pid |  |
| $! | 上一个脚本pid |  |
| $_ | 上一个脚本的参数或脚本名称 |  |

### 变量扩展

不会修改变量本身

| 形式 | 含义 | 说明 |
| --- | --- | --- |
| ${VAR} | 变量输出 |  |
| ${#VAR} | 变量长度 |  |
| ${VAR:offset:length} | 变量截取 |  |
| ${VAR#prefix} | 变量删除 ## 贪婪 | ${name##*/} 文件名，等同dirname |
| ${VAR%suffix} | 变量删除 %%贪婪 | ${name%/*} 文件路径，等同pathname |
| ${VAR/from/to} | 变量替换 // 全局 |  |
| ${VAR:-default} | 变量默认值， 不改变变量的值 |  |
| ${VAR:=default} | 变量默认值，改变变量的值 |  |
| ${VAR:?errMessage} | 变量错误输出 |  |
| ${VAR:+replace} | 变量存在替换内容 |  |
