## Git提交日志规范

### Conventional Commits

`<type>(<scope>): <subject>`

| type | 说明 |
|------|------|
| `feat` | 新功能 |
| `fix` | 修复 bug |
| `docs` | 文档变更 |
| `style` | 代码格式化（不影响逻辑） |
| `refactor` | 重构（非 feat/fix） |
| `perf` | 性能优化 |
| `test` | 测试 |
| `chore` | 构建/工具链 |
| `ci` | CI/CD 配置 |
| `revert` | 回滚 |

### 示例

```
feat(auth): add JWT token refresh
fix(order): correct discount calculation for bulk orders
docs(api): document pagination parameters
```

### 提交原则

- 每个提交只做一件事
- 首行 ≤72 字符
- 用英文或中文，团队统一即可
- `BREAKING CHANGE:` 标记不兼容变更
