## 更新证书

```yaml
wget https://www.cacert.org/certs/ca-bundle.crt -O ca-bundle.crt

scp ca-bundle.crt root@your_server:/root/
sudo mv /root/ca-bundle.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust extract
openssl s_client -connect ollama.com:443 -CApath /etc/ssl/certs

```
