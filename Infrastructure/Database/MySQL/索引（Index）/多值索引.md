## 多值索引

> MySQL 8.0.17+ 支持在 JSON 数组列上创建多值索引 (Multi-Valued Index)。

### 创建语法

```sql
CREATE TABLE t1 (
    id INT PRIMARY KEY,
    data JSON
);

-- 在 JSON 数组上创建多值索引
CREATE INDEX idx_data ON t1 ((CAST(data->'$.tags' AS UNSIGNED ARRAY)));

-- 查询时自动使用索引
SELECT * FROM t1 WHERE 10 MEMBER OF(data->'$.tags');
```

### 使用限制

| 限制 | 说明 |
|------|------|
| 仅 InnoDB | 不支持其他引擎 |
| 仅 JSON ARRAY | 支持 INTEGER/CHAR/DATE/TIME/ARRAY 类型 |
| MEMBER OF / JSON_CONTAINS | 仅这两个函数能利用多值索引 |
| 不支持排序 | 多值索引不能用作 ORDER BY |

### 适用场景

- JSON 数组字段的精确匹配查询
- 标签、分类等多值属性列
- 替代 JSON_CONTAINS 全表扫描
