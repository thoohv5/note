## 压缩和解压类

### gz

```bash
gzip dirname
gunzip xxx.gz
```

### zip

```bash
zip -r xxx.zip dirname
unzip xxx.zip -d dirname
```

```jsx
yum install zip unzip -y
```

### tar

```bash
tar -zcvf xxx.tar.gz dirname
tar -zxvf xxx.tar -d dirname
```
