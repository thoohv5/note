# which

查看可执行文件的位置，在**PATH**变量指定的路径中，搜索某个系统命令的位置，并且返回**第一个**搜索结果

```
which command

```

### 与`whereis`的区别

- whereis 命令可以在查找到二进制命令的同时，也查找到帮助文档的位置
- 而which命令在查找到二制命令的同时，如果这个命令有别名，则还可以找到别名命令。
