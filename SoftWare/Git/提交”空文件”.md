## 提交”空文件”

```yaml
mkdir empty-dir
touch empty-dir/.gitkeep

git add empty-dir/.gitkeep
git commit -m "Add empty directory with .gitkeep"

git commit --allow-empty -m "Empty commit"

.gitkeep 只是一个习惯叫法，你也可以用 .keep、README.md 等。
```
