## 长事务筛选

```sql
-- 筛选执行时长超过60秒的长事务，关联processlist获取客户端信息
SELECT
    t.trx_id AS 事务ID,
    t.trx_started AS 开始时间,
    TIMESTAMPDIFF(SECOND, t.trx_started, NOW()) AS 执行时长_秒,
    t.trx_query AS 执行SQL,
    p.user AS 数据库用户,
    p.host AS 客户端IP,
    p.db AS 操作数据库,
    p.command AS 连接状态,
    p.time AS 连接已运行时间,
    t.trx_lock_structs AS 持有的锁数量
FROM
    information_schema.innodb_trx t
JOIN
    information_schema.processlist p ON t.trx_mysql_thread_id = p.id
WHERE
    TIMESTAMPDIFF(SECOND, t.trx_started, NOW()) > 60  -- 筛选超过60秒的长事务
    AND t.trx_state = 'RUNNING'
ORDER BY
    执行时长_秒 DESC;
```
