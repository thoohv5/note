## 修改镜像

```bash
kubectl set image deployment/nginx-deployment nginx=nginx:1.91
```

```bash
kubectl patch statefulset mysql --type='json' -p='[{"op": "replace", "path": "/spec/template/spec/containers/0/image", "value":"mysql:5.7.23"}]'
```
