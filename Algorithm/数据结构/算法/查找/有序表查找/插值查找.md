# 插值查找

## 概念

插值查找（Interpolation Search）是根据要查找的关键字key与查找表中最大最小的记录的关键字比较后的查找方法，其核心就在于插值的计算公式

![](https://raw.githubusercontent.com/thoohv5/ob/main/picture202401151336123.png)

### 时间复杂度

```jsx
O(logn)

```

### 优劣

1. 对于数据量较大，关键字分布比较均匀的查找表来说，采用插值查找, 速度较快.
2. 关键字分布不均匀的情况下，该方法不一定比折半查找要好
