## 函数索引

函数索引 = 虚拟列 + 索引（底层实现）

- **概念**：对列的计算结果建立索引，而不是列本身。
- **MySQL 8.0+ 支持**。

```sql
-- 对 LOWER(name) 建立索引，支持大小写不敏感查询
CREATE INDEX idx_name_lower ON t((LOWER(name)));

-- 查询可以走索引
SELECT * FROM t WHERE LOWER(name) = 'alice';
```
