# 文件目录类

### 切换目录

```bash

# 家目录
cd ~
# 上次的目录，不存在时 -bash: cd : OLDPWD not set
cd -
```

### 创建目录

```bash
mkdir -p dir
```

### 删除目录

```bash
rm -rf dir
```

### 创建文件

```bash
touch file
```

### 复制

```bash
cp -r source dest

# 没有提示
\cp 
```

<aside>
💡 覆盖提示 alias cp -i

</aside>

### 移动

```bash
mv
```

### 查看

```bash
# 查看并显示行号
cat -n file
```

```bash
more

# 向上翻页 -- Crtl + F
# 向下翻页 -- Crtl + B / Space

# 向下翻行 -- Enter

# 退出 -- q 
```

```bash
less

# 向上翻页 -- Crtl + F
# 向下翻页 -- Crtl + B / Space

# 向下翻行 -- Enter

# 退出 -- q 

# 向下搜索；n-向下查找；N-向上查找
/字串

# 向上搜索；n-向下查找；N-向上查找
?字串
```

```bash
head

# 文件前number行,默认显示前10行
head -n number file
```

```bash
tail

# 文件后number行,默认显示后10行
tail -n number file

# 追踪
tail -f file
```

<aside>
💡 tailf，tail -F, tail -f

</aside>

```bash
tail -f
	等同 --follow[={descriptor}]
	根据文件描述符进行追踪，当前文件改名或者被删除，追踪停止

tail —F
	等同 --follow[={name}] --retry
	根据文件名进行追踪，当前文件改名或者被删除，如果再次创建相同的文件，会继续追踪

tailf 
	等同 tail -n 10 -f file
	区别：如果文件不增长，它不会去访问磁盘文件
```

### 链接

```bash
ln -s source target
```

### history

```bash
echo $HISTSIZE

cat ~/.bash_history

history 10

# 清空
history -c

# 恢复历史
history -r file

# 命令回放
!number

# 执行上次的命令
!!

```
