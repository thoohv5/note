# 输入/输出

## 标准输出函数`print()`

```python
print(self, *args, sep=' ', end='\n', file=None)
```

选项

- sep 输出项之间的分割字符串
- end 最后输出值

### 格式化输出

常见的格式转换符有:

- `%d`:整数
- `%f`:浮点数
- `%s`:字符串
- `%p`:数据的内存地址(十六进制)

```python
name = 'Wang'
score = 56.345
print("学生 %s 的分数是 %.2f" %(name, score)) # 学生 Wang 的分数是 56.34
```
