## 0.1 电脑：辅助人脑的好工具

现在的几乎无时无刻都会碰到电脑！不论是桌面电脑（台式机）、笔记本电脑、平板电脑、智能手机等等，这些都是电脑。 虽然接触的这么多，但是，你了解电脑里面的元件有什么吗？以台式机来说，电脑的机箱里面含有什么元件？不同的电脑可以应用在哪些工作？ 你生活周遭有哪些电子用品内部是含有电脑相关的元件的？下面我们就来谈一谈这些东西！

所谓的电脑就是一种计算机，而计算机其实是："接受使用者输入命令与数据，经由中央处理器的数学与逻辑单元运算处理后， 以产生或储存有用的信息"。因此，只要有输入设备 （不论是键盘还是触摸屏） 及输出设备 （例如电脑屏幕或直接由打印机打印出来），让你可以输入数据使该机器产生信息的， 那就是一部计算机了。

> [!TIP]
> 电脑可以帮助人们进行大量的运算！以前如果要计算化学反应式都得要算个老半天，有了电脑仿真软件后，就有不一样的情况发生了！ 以下图为例，鸟哥的工作中，有一项是需要将人们排放的空气污染物带入电脑模式进行仿真后，计算出可能产生的空气品质并得到空气品质状态，最后经过分析软件得到各式各样的图表。 经过这些图表的分析，就可以让人们知道什么样的污染排放来可能会产生什么样的空气品质变化咧。

根据这个定义你知道哪些东西是计算机了吗？包括一般商店用的简易型加减乘除计算机、打电话用的手机、开车用的卫星定位系统 （GPS）、提款用的提款机 （ATM）、你上课会使用的桌上型个人电脑、外出可能会带的笔记本电脑 （包括 notebook 与 netbook），还有近几年前 （2015年前后） 非常热门的平板计算机与智能手机， 甚至是未来可能会大流行的单板电脑 （Xapple pi, banana pi, Raspberry pi, [1]） 与智能手表，乃至于更多的智能穿戴式电脑等等，这些都是计算机！

那么计算机主要的组成元件是什么呢？下面我们以常见的个人电脑主机或服务器工作站在主机来说明好了。

### 0.1.1 计算机硬件的五大单元

关于电脑的硬件组成部分，其实你可以观察你的台式机来分析一下，依外观来说这家伙主要可分为三部分，分别是：

- 输入单元：包括键盘、鼠标、读卡机、扫描仪、手写板、触摸屏等等一堆；
- 主机部分：这个就是系统单元，被主机机箱保护住了，里面含有一堆板子、CPU 与内存等；
- 输出单元：例如屏幕、打印机等等

我们主要通过输入设备输入到主机当中，然后再由主机来处理数据与运算，最后经由输出单元来呈现结果！整个工作中最重要的就是**主机**！ 因为在主机部分又分为几大单元：

- **控制单元**：主要是协调各组件与各单元间的工作
- **算术逻辑单元**：主要是进行"算术运算"与"逻辑判断"

而**内存**则是作为数据存放的地方！数据流入/流出内存都是通过控制单元来下达命令的！控制单元主要协调各组件工作

### 0.1.2 一切设计的起点：CPU 的种类

CPU 的全称是"中央处理器"，它是具有特定功能的芯片，里头含有微指令集。CPU 的设计主要分为两种主要设计理念，这两种设计理念完全影响了这整部电脑的架构与性能！

- **精简指令集（Reduced Instruction Set Computer, RISC）**
  - 这种 CPU 的设计中，微指令集较为精简，每个指令的执行时间都很短，指令的执行性能较佳；但是要做复杂的事情时，可能需要由多个指令来完成
  - 常见的 RISC 微指令集 CPU 主要有：
    - **SPARC** 系列：常用于学术领域的大型工作站中
    - **Power** 系列：例如 Sony 的 PlayStation 3（Cell 处理器）就是使用 Power 架构
    - **ARM** 系列：常使用的手机、PDA、导航系统、网络设备等，绝大部分都是使用 ARM 架构的 CPU！商业应用产品非常广泛

- **复杂指令集（Complex Instruction Set Computer, CISC）**
  - 与 RISC 不同的，CISC 在微指令集的地面上，每个微指令可以执行一些较低阶的硬件操作，指令数目多而且复杂，每条指令的长度并不相同
  - 因为 CISC 微指令集较为复杂，所以每条指令花费的时间较长，但每条个别指令可以处理的工作较为丰富
  - 常见的 CISC 微指令集 CPU 主要有：
    - **AMD** 处理器
    - **Intel** 处理器
    - **VIA** 处理器

> [!NOTE]
> 在 Intel 兼容平台上面常见的操作系统除了 Windows 之外，其实还有 Linux、Unix 等多样化的操作系统！ AMD 近几年也是有慢慢地在提升他的技术质量！
>
> 另外，得注意的是，在 2003 年以后 Intel 开发的 CPU 强制纳入了 MMX, SSE, SSE2, SSE3, SSE4, AMD64, EMT64, x86, x86-64 等指令集！因此而催生了新的操作系统与相关软件的发展！

### 0.1.3 接口设备

除了前面提到的两大单元之外，还需要有许多的接口设备来将数据送达或离开计算机！在整个系统里，最重要的当然就是 CPU 与内存啦！但是数据得要能输入到电脑当中处理，然后能够输出结果给人使用！这时接口设备的重要性就体现出来了！

常见的接口设备：

| 设备 | 说明 |
|------|------|
| 主板 | 负责将所有设备连接起来，让所有设备能够协调与通信！ |
| 存储设备 | 如硬盘、软盘、光盘、磁带等 |
| 显示设备 | 屏幕适配器（VGA, PCI-e 插槽）、显示标准 |
| 网络设备 | 调制解调器（猫）、以太网路等 |

### 0.1.4 运作流程

简单来说，整个电脑的运作流程是：

1. **输入单元**（键盘、鼠标、触摸屏等）接收用户输入的数据
2. 数据通过**控制单元**送到**内存**
3. **算术逻辑单元（CPU）** 从内存读取数据进行处理
4. 处理后的数据结果存回**内存**
5. **控制单元**将结果送往**输出单元**（屏幕、打印机等）

> [!IMPORTANT]
> 整个活动中最重要的就是**脑袋瓜**！ 而脑袋瓜当中与现在正在进行的工作有关的就是 CPU 与内存！任何外界的接触都必须要由脑袋瓜中的内存记录下来， 然后给脑袋瓜中的 CPU 依据这些数据进行判断后，再发布命令给各个周边设备！
>
> 如果需要用到过去的经验，就得由过去的经验（硬盘）当中读取到现在的记忆（内存）当中，再交由 CPU 来判断咧！这 点得要再次的强调啊！

### 0.1.5 电脑按用途分类

知道了电脑的基本组成与周边设备，也知道其其实电脑的 CPU 种类非常的多，再来我们想要了解的是，电脑如何分类？电脑的分类非常多种，如果以电脑的复杂度与运算能力进行分类的话，主要可以分为这几类：

- **超级计算机（Supercomputer）**
  超级计算机是运行速度最快的电脑，但是他的维护、操作费用也最高！主要是用于需要高速计算的计划中。 例如：国防军事、气象预测、太空科技，用在仿真的领域较多。详细信息也可以参考： 国家高速网络与计算中心 http://www.nchc.org.tw 的介绍！ 至于全世界最快的前 500 大超级计算机，则请参考：http://www.top500.org/。

- **大型计算机（Mainframe Computer）**
  大型计算机通常也具有数个高速的 CPU，功能上虽不及超级计算机，但也可用来处理大量数据与复杂的运算。 例如大型企业的主机、全国性的证券交易所等每天需要处理数百万笔数据的企业机构， 或者是大型企业的数据库服务器等等。

- **迷你电脑（Minicomputer）**
  迷你电脑仍保有大型计算机同时支持多使用者的特性，但是主机可以放在一般作业场所，不需要像前两个大型计算机需要特殊的空凋场所。 通常用来作为科学研究、工厂的流程管理与分析等。

- **工作站（Workstation）**
  工作站的价位又比迷你电脑便宜许多，是针对特殊用途而设计的电脑。在个人电脑的性能还没有提升到目前的状态之前， 工作站电脑的性能/价格比是所有电脑当中较佳的，因此在学术研究与工程分析方面相当常见。

- **微电脑（Microcomputer）**
  个人电脑就属于这部份的电脑分类，体积最小，价格最低，但功能也是五脏俱全的！大致又可分为桌上型、笔记本型等。

> [!TIP]
> 若光以性能来说，目前的个人电脑性能已经够快了，甚至已经比工作站等级以上的电脑运算速度还要快！ 但是工作站电脑强调的是稳定不死机，并且运算过程要完全，因此工作站电脑强调的是稳定不死机，并且运算过程要完全！所以在某些情况下，非工作站电脑不可！

### 0.1.6 速速单位

电脑的运算能力除了 CPU 的微指令集设计理念有关之外，其实还与他的频率有关！而频率就是 CPU 每秒钟可以进行的工作次数。 所以频率越高表示 CPU 单位时间内可以处理的工作越多。不过，频率有不同的单位！常见的单位：

- **Hz**：就是"次数/秒"的意思
- **MHz**：Mega-Hertz，百万 Hz
- **GHz**：Giga-Hertz，十亿 Hz

> [!NOTE]
> 什么是"位"呢？以人类最常用的十进制为例，每个"位置"上面最多只能有一个数值，这个数值不能比 9 还要大！那比 9 还要大怎么办？ 就用"第二个位置来装一个新的 1 "！所以， 9 还是只有一个位置， 10则是用了两个位置了。好了如果说是 16 进制怎么办？由于每个位置只能出现一个数值， 但是数字仅有 0~9 而已呀！因此 16 进制中，就以 A 来代表 10 的意思，以 B 来代表 11 的意思，所以 16 进位就是 0~9, a, b, c, d, e, f，有没有看到， "每个位置最多还是只有一个数值而已"啦！

### 速度单位

个人电脑常用来作为通讯的介面设备——调制解调器（猫）——速度单位 Bytes/s ！而电脑其实也是网络速度的单位！常见的单位：

- **Mbps**： Mega bits per second，即 Mb/s，megabits
- **MB/s**： Mega Bytes per second，即 MB/s，megabytes

### 容量单位

容量方面，GB 是常见的单位之一！但是需要注意的是，容量单位进位是 1024 为转换，而不是 1000！即 1GB = 1024MB，而 1MB = 1024KB！

> [!NOTE]
> 为什么硬盘容量的单位计算出来不太一样？例如你买了一个 500GB 的硬盘，但是格式化后仅剩 466GB 左右？为什么喔？因为硬盘制造商的计算单位是用十进位！而且 1GB = 1000 x 1000 x 1000 byte 喔！但是根据 1024 的进位来看， 500GB 应该等于 500 x 1024 x 1024 x 1024 bytes 才对！ 因此这就是答案啦！

### 字组大小（Word size）

依据 CPU 每次运算能够处理的数据量来区分，又可以分为：

- **32 位**：每次能够处理的数据量是 32 bits，大约 4GB 左右的内存
- **64 位**：每次能够处理的数据量是 64 bits，大约 16GB 以上的内存

本章节主要包含：

### 重点回顾

- 计算机的定义为："接受使用者输入命令与数据，经由中央处理器的数学与逻辑单元运算处理后，以产生或储存有用的信息"的装置
- 计算机的五大单元包括：输入单元、输出单元、控制单元、算术逻辑单元、记忆单元（含内存与显存）
- CPU 的设计理念主要分为 RISC（精简指令集）与 CISC（复杂指令集）两大主流
- CPU 的频率使用 Hz 这样的单位，1 GHz = 1000 x 1000 x 1000 Hz
- 由于磁盘的最小计量单位为 sector，通常磁盘容量采用十进位来处理
