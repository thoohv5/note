# MCP

# 概述

MCP （Model Context Protocol，模型上下文协议）为连接 AI 系统和数据源提供了一个通用的开放标准，用单一协议取代了分散的集成。换一个说法是**以一致的方式将各种数据源、工具和功能连接到 AI 模型**中间协议。
