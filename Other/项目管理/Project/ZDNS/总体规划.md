# 总体规划

# 项目维护

1. 保持项目的稳定运行，修复历史bug
2. 迭代非核心的外围功能（最好不进行新功能开发）

# 重构

1. 前后端交互，最好能够做到前端支持配置开发，（在开发新功能的时候，无需前端支持）
2. 功能梳理，梳理现有功能，归类核心公共，重要功能，边缘功能，定制功能
3. 业务层与DHCPD的交互整体，提高稳定性，提供架构可扩展性

### 前端方案

1. 新的前端，就跳出来，需要考虑公共部分，权限，告警，日志怎么处理
2. 原来的界面，改动
