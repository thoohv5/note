# 版本控制策略

### 版本控制策略

1. URI
    
    `http://server:port/api/version/customer/123`
    
    好处： 直接可以在URI中直观的看到API版本，可以直接在浏览器的查看各个版本API的结果。
    
    坏处： 版本号在URI中破坏了REST的HATEOAS（hypermedia as the engine of application state）规则。版本号和资源之间并无直接关系。
    
2. Request Parameter
    
    `http://server:port/api/customer/123?version=2`
    
    好处/坏处 同上
    
3. Media Type
    
    `Content-Type: application/x-www-form-urlencoded`<br/>
    `Host: server`<br/>
    `Content-Length: 48`<br/>
    `version : 1`<br/>
    
    好处： 遵循了REST的设计风格，
    
    坏处： 版本不直观，需要能设置header的client才能调用查看该API的效果。
