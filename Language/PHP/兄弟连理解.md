## 兄弟连理解

1、PHP中unset()和null的区别

```
1、unset只会销毁当前变量，不影响引用赋值变量 
2、=null并未销毁当前变量，只是未赋值，影响引用赋值变量
```

2、PHP默认为false的情况

```
1、布尔值false
2、整数型值0  
3、浮点型值0.0  
4、空字符串，以及字符串"0"  
5、特殊类型null（包括尚未赋值的变量）
6、空标记生成的SimpleXML对象
特殊
1、0.00、0.000
```

"0"(false) "0.0"(true) "0.00"(true) "0000"(true) 空对象(true)

### 正则

在PHP中，有两套正则的处理函数库：PCRE和POSIX。前者以preg_前缀命名，与Perl兼容；后者以ereg_前缀命名。二者功能相似，但PCRE的效率略高。

### 原子

1. \d \D 数字(0-9)
2. \w \W 变量命名规则(a-z A-Z 0-9 _)
3. \s \S 空白(\t\r\n\f\v)
4. [] [-] [^]
5. .	匹配所有的字符除了换行符

### 元字符

1. `*` 0个1个或者多个
2. `+`	1个或者多个
3. `?`	0个或者1个
4. `{n} {n,} {n,m}`
5. `|`
6. `^/\\A $/\\Z`
7. `\\b \\B` 单词边界
8. `() ?: \\1`

### 模式修正符

1. i 不区分大小写
2. m 默认情况下多行字符按照一行处理，主要是针对^$
3. s .匹配所有字符包括换行符
4. x 可以省略空白字符的匹配
5. e ==替换变量可以使用PHP函数==
6. U (. * +) 正则比较贪婪=>不贪婪 等同于在元字符后面加上? ?和U不能同时使用
