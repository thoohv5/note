## 修改/删除字段

### `不支持直接修改字段的名称`

```bash
## 修改原表的名称
ALTER TABLE table RENAME TO tableOld;
## 新建修改字段后的表
CREATE TABLE table(ID INTEGER PRIMARY KEY AUTOINCREMENT, Modify_Username text not null);
## 从旧表中查询出数据 并插入新表
INSERT INTO table SELECT ID,Username FROM tableOld;
## 删除旧表
DROP TABLE tableOld;
```
