# 笔记属性标准

## 属性格式 (YAML Frontmatter)

**属性顺序必须一致，所有属性必填：**

```yaml
---
title: 文档标题
date: 2024-01-01
tags: [一级分类, 二级分类, 三级分类]
type: note|guide|reference|cheatsheet
status: incomplete|complete|review
---
```

> [!important] 规则
> - **属性顺序必须固定**：title → date → tags → type → status
> - **所有属性必填**：不允许删除任何属性，不允许留空
> - **移动文件时自动调整**：tags 必须根据新目录路径自动更新

## 属性说明

| 属性     | 必填 | 说明                                         | 示例                                              |
| -------- | ---- | -------------------------------------------- | ------------------------------------------------- |
| `title`  | 必填 | 文档标题，与文件名对应                       | `Redis 概述`                                      |
| `date`   | 必填 | 创建日期，格式 YYYY-MM-DD                    | `2024-01-01`                                      |
| `tags`   | 必填 | 标签，与目录路径一致，用于分类和检索         | `[编程语言, Golang]` 或 `[基础设施, 数据库, MySQL]` |
| `type`   | 必填 | 笔记类型                                     | `note` / `guide` / `reference` / `cheatsheet`     |
| `status` | 必填 | 完成状态                                     | `incomplete` / `complete` / `review`              |

### 必填属性详细规则

#### 1. title（标题）
- 必须与文档主题一致
- 建议与文件名（去掉扩展名）保持一致
- 禁止留空

#### 2. date（日期）
- 格式：`YYYY-MM-DD`
- 使用文件创建日期
- 禁止留空

#### 3. tags（标签）
- **必须与目录路径严格对应**
- 一级目录 → 一级标签
- 二级目录 → 二级标签
- 三级目录 → 三级标签（可选）
- 移动文件时必须自动更新
- 禁止留空

#### 4. type（类型）
- 可选值：
  - `note`：普通学习笔记
  - `guide`：操作指南/教程
  - `reference`：参考资料/文档
  - `cheatsheet`：速查表
- 禁止留空

#### 5. status（状态）
- 可选值：
  - `incomplete`：未完成/草稿
  - `complete`：已完成
  - `review`：待复查
- 禁止留空

### source 填写规则

| 来源类型   | 填写方式                      | 示例                                          |
| ------ | ------------------------- | ------------------------------------------- |
| 原创笔记   | 不填或留空                     | —                                           |
| 网页收集   | 原文 URL                   | `https://mp.weixin.qq.com/s/xxx`             |
| AI 对话   | AI 产品名                    | `Gemini` / `ChatGPT` / `Claude`             |
| 书籍     | `《书名》`                    | `《Go 语言圣经》` / `《高性能MySQL》`                   |
| 官方文档   | `官方文档`                   | `官方文档`                                      |
| 课程     | 课程名                       | `花生十三` / `粉笔系统班`                              |
| 面试记录   | 面试人名                      | `张三`                                        |

## 标签体系 (tags)

标签与目录路径一一对应，层级与目录层级一致。

> [!important] 规则
> - 标签层级与目录路径一致：`Infrastructure/Database/MySQL/` → `[基础设施, 数据库, MySQL]`
> - 尽量加标签，能标多深就标多深
> - 不要使用引号包裹标签值
> - 不要使用 `clippings` 等非目录标签，用标准分类标签替代
> - 标签名称与目录名对应：目录名是中文用中文，是英文用英文

## 网页收集

网页收集笔记存放在 `WebClipper/` 目录下，按主题分子目录。

### Obsidian Web Clipper 配置

插件 ID: `cnjifjpddelmedmihgijeibhnjfabmlf`

配置模板：

```yaml
author: "{{author|split:", "|wikilink|join}}"
created: "{{date}}"
description: "{{description}}"
published: "{{published}}"
source: "{{url}}"
tags: [收集, 一级分类, 二级分类]
title: "{{title}}"
type: reference
```

> [!tip] 配置要点
> - `tags` 第一个固定为 `收集`，再加分类标签
> - `type` 固定为 `reference`
> - 收集的笔记存入 `WebClipper/` 对应子目录
> - `source` 字段同时写入标准属性的 `source`
