# 访问仓库

## `Docker Hub`

### 注册&登录

```docker
# 登录docker hub
docker login -u thooh -p xxx

# 登出
docker logout
```

### 拉取镜像

```docker
# 搜索
docker search 仓库名[:标签]

# 拉取
docker pull 仓库名[:标签]
```

### 推送镜像

```docker
# 打包
docker tag 仓库名[:标签] 仓库名[:标签]

# 镜像发布
docker push 仓库名[:标签]
```
