# 运行级别

### 运行级别

- 0-关机
- 1-单用户（找回丢失密码）
- 2-多用户状态没有网络服务
- 3-多用户状态有网络服务
- 4-系统未使用保留给用户
- 5-图形界面
- 6-系统重启

### 切换

```bash
init [0123456]
```

## 设置运行级别

### CentOS < 7

```bash
vim /etc/inittab
```

### CentOS ≥ 7

```bash
# 获取运行级别
systemctl get-default

# 设置运行级别
#
# multi-user.target 多用户-3
# graphical.target 图形-5
systemctl set-default xxx
```

## Centos7重置密码

1. 关机重启电脑，进入系统选择界面，按快捷键 e 进入编辑界面
2. 查找Linux16，在行末输入 `init=/bin/sh`,  快捷键 `ctrl + x` 进入单用户模式
3. 输入 `mount -o remount,rw /`
4. `passwd`  修改密码
5. 输入 `touch /.autorelabel` 
6. 输入`exec /sbin/init`
