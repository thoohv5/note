# 磁盘分区挂载

### 挂载情况

```bash
# list block devices
lsblk

# 详细信息
lsblk -f
```

### 分区

```bash
fdisk /dev/sdb

n
p
1
w
```

### 格式化

```bash
mkfs -t ext4 /dev/sdb1
```

### 挂载

```bash
mkdir disk
mount /dev/sdb1 disk
```

<aside>
💡 命令挂载是临时的，重启失效

</aside>

**永久挂载**

```bash
vim /etc/fstab

# 立即生效
mount -a
```

### 卸载

```bash
umount /dev/sdb1
```

### 查看

```bash
# 磁盘使用情况
df -h

# 磁盘占用情况
du -hac --max-depth=1 /opt

h - human
a - 含文件
--max-depth=1 子目录深度
-c 列出明细以及汇总值
```

### 挂载流程

1. 添加硬盘，重启
2. 硬盘分区
3. 硬盘格式化
4. 硬盘挂载
