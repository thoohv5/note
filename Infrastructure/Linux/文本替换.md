# 文本替换命令

## sed 替换
sed -i 's/old/new/g' file.txt       # 替换文件中所有匹配
sed -i 's/old/new/' file.txt        # 只替换每行第一个
sed -i 's/old/new/2' file.txt       # 替换每行第2个
sed -i '10,20s/old/new/g' file.txt   # 替换10-20行

## 递归替换（macOS 注意）
# Linux
find . -name "*.txt" -exec sed -i 's/old/new/g' {} +
# macOS（需加空备份参数）
find . -name "*.txt" -exec sed -i '' 's/old/new/g' {} +

## perl 替换（跨平台一致性更好）
perl -pi -e 's/old/new/g' file.txt
find . -name "*.txt" -exec perl -pi -e 's/old/new/g' {} +

## 场景
- 批量修改配置文件
- 代码中批量重命名变量/路径
- 日志分析预处理

## 注意事项
- macOS sed 的 -i 必须带备份扩展名（如 -i ''）
- 对二进制文件慎用
