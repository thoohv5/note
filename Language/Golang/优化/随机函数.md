## 随机函数

## math/rand

`math/rand`包是标准库对[伪随机数](https://zhida.zhihu.com/search?content_id=240293583&content_type=Article&match_order=1&q=伪随机)B0&zhida_source=entity的实现，可以生成整型和[浮点型](https://zhida.zhihu.com/search?content_id=240293583&content_type=Article&match_order=1&q=浮点)8B&zhida_source=entity随机数

对应`rand`包大致可以分为1.20前和后

之前的`rand`包，对应随机数的生成需要设置相应的随机数种子，通常我们以时钟，输入输出等节点作为种子使用；对应没有设置种子的情况可以理解为种子是1；

1.20后，`math/rand`包自动为全局随机数生成器提供随机值，废弃了`Seed`（设置随机数）函数，如果需要之前的可重现[随机数序列](https://zhida.zhihu.com/search?content_id=240293583&content_type=Article&match_order=1&q=随机数序)97&zhida_source=entity可以使用`rand.New(rand.NewSource(seed))`自行设置随机源

```go
package main

import (
	"fmt"
	"math/rand"
	"time"
)

var creatures = []string{"shark", "jellyfish", "squid", "octopus", "dolphin"}

// 必须的，不然是固定的数据（非随机的数据)
// func init() {
//	rand.Seed(time.Now().UTC().UnixNano())
//}
// version1.20
// r := rand.New(rand.NewSource(time.Now().UnixNano()))

func main() {
	i := rand.Intn(len(creatures))
	fmt.Println(i, creatures[i])
}

```

### `io.ReadFull`

```go
b := make([]byte, 16) // 16 字节 = 128-bit
if _, err := io.ReadFull(rand.Reader, b); err != nil {
	panic(err)
}
```

## `crypto/rand`

加密安全的随机数生成器

```go
package main

import (
	"crypto/rand"
	"fmt"
	"math/big"
)

func main() {
	fmt.Println(rand.Int(rand.Reader, big.NewInt(6)))
}

```
