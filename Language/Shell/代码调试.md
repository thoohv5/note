## 代码调试

### ## set -x

- x(xtrace) 选项会导致 BASH 在执行命令之前，先把要执行的命令打印出来。

```
set -x

script

set +x

```

### trap/bashdb

```
trap [-lp] [[arg] sigspec ...]

```

sigspec 包括 `<signal.h>` 中定义的各个 signal， EXIT，ERR，RETURN 和 DEBUG
