## 单串线性 DP 问题

```
单串线性 DP 问题：问题的输入为单个数组或单个字符串的线性 DP 问题。状态一般可定义为 dp[i]，表示为：

1. 「以数组中第 i 个位置元素 nums[i] 为结尾的子数组（nums[0]...nums[i]）」的相关解。
2. 「以数组中第 i−1 个位置元素 nums[i−1] 为结尾的子数组（nums[0]...nums[i−1]）」的相关解。
3. 「以数组中前 i 个元素为子数组（nums[0]...nums[i−1]）」的相关解。

```
