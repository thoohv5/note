# 配置相关

# 配置获取

```
# vesion 2.0.0
CONFIG GET parameter [parameter ....]

```

`CONFIG GET` 命令用于读取正在运行的Redis服务器的配置参数。 Redis 2.4 并不支持所有配置参数，而 Redis 2.6 可以使用此命令读取服务器的整个配置。

用于在运行时更改配置的对称命令是 `CONFIG SET` 。

# 配置设置

```
# version 2.0.0
CONFIG SET parameter value [parameter value ...]

```

`CONFIG SET` 支持的配置参数列表可以通过发出 `CONFIG GET *` 命令来获取，该命令是用于获取有关正在运行的 Redis 实例的配置信息的对称命令。

所有使用 `CONFIG SET` 设置的配置参数都会立即被 Redis 加载，并在下一条命令执行时生效。

# 配置重写

```
# version 2.8.0
CONFIG REWRITE

```

`CONFIG REWRITE` 命令重写服务器启动时使用的 `redis.conf` 文件，应用使其反映服务器当前使用的配置所需的最小更改，该配置可能与原始配置不同其一是因为使用了 `CONFIG SET` 命令。

重写以非常保守的方式执行：

- 尽可能保留原redis.conf的注释和整体结构。
- 如果旧的 redis.conf 文件中已存在某个选项，则会在同一位置（行号）重写该选项。
- 如果某个选项尚不存在，但已设置为默认值，则重写过程不会添加该选项。
- 如果某个选项尚不存在，但设置为非默认值，则会将其附加到文件末尾。
- 未使用的行被消隐。例如，如果您曾经有多个 `save` 指令，但当您禁用 RDB 持久性时，当前配置中的指令较少或没有，则所有行都将被清空。

如果原始配置文件由于某种原因不再存在，CONFIG REWRITE 还可以从头开始重写配置文件。但是，如果服务器在根本没有配置文件的情况下启动，则 CONFIG REWRITE 将仅返回错误。
