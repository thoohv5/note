# 红眼睛和蓝眼睛

**红眼睛和蓝眼睛：一个岛上有100个人，其中有5个红眼睛，95个蓝眼睛。这个岛有三个奇怪的宗教规则。**

1.他们不能照镜子，不能看自己眼睛的颜色。

2.他们不能告诉别人对方的眼睛是什么颜色。

3.一旦有人知道了自己是红眼睛，他就必须在当天夜里自杀。

某天，有个旅行者到了这个岛上。由于不知道这里的规矩，所以他在和全岛人一起狂欢的时候，不留神就说了一句话：【你们这里有红眼睛的人。】

问题：假设这个岛上的人每天都可以看到其他所有人，每个人都可以做出缜密的逻辑推理，请问岛上会发生什么？

岛上有一个红眼睛

第一天因为没有看见红眼睛，确实自己是红眼睛，所以第一天晚上自杀

岛上有两个红眼睛

第一天因为看见有一个红眼睛，所以第一天晚上不会自杀

第二天因为看见那个红眼睛没有自杀，确定自己也是红眼睛，所以第二天晚上自杀，另外一个红眼睛同理

岛上有三个红眼睛

第一天因为看见有两个红眼睛，所以第一天晚上不会自杀

第二天因为看见有两个红眼睛，所以第二天晚上不会自杀

第三天因为看见那你那个红眼睛没有自杀，确定自己也是红眼睛，所以第三天晚上自杀，其他红眼睛同理
