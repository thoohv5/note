# 使用指南

**最佳实践建议**
1. **伪目标声明**：用`.PHONY`标记非文件生成类命令
2. **环境变量管理**：将API_KEY等敏感信息通过`export`注入
3. **帮助文档**：添加`help`目标说明所有命令功能

### 跨平台编译

```makefile
PLATFORMS = linux windows darwin
ARCHS = amd64 arm64

cross-build:
 @mkdir -p release
 @for os in $(PLATFORMS); do \
  for arch in $(ARCHS); do \
   GOOS=$$os GOARCH=$$arch go build \
    -o release/$(BINARY_NAME)-$$os-$$arch ; \
  done \
 done
```

### 智能变量

```makefile
# 自动获取所有.go文件
SOURCES = $(shell find . -name '*.go')
```
