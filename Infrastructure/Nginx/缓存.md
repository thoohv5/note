# 缓存

# 浏览器缓存（前端缓存）

**概念**：浏览器把静态资源（HTML/JS/CSS/图片）缓存在本地，下次访问可直接读取，不请求服务器。

**控制方式**：

- `Expires` → 指定过期时间（HTTP/1.0）
- `Cache-Control` → 指定缓存策略（HTTP/1.1）
- **示例**：
    
    ```css
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|woff2?)$ {
        root /usr/share/nginx/html;
        expires 30d;  # 浏览器缓存 30 天
        add_header Cache-Control "public";
    }
    ```
    

---

- **浏览器现象**
    1. 首次请求及返回
    
    ```
    # 返回
    HTTP/1.1 200 OK
    Last-Modified: Fri, 26 Sep 2025 03:52:17 GMT
    ETag: "68d60df1-22"
    Expires: Fri, 26 Sep 2025 05:58:50 GMT
    ```
    
    1. 缓存期间请求(不会发起请求)
    
    ```
    from disk cache
    ```
    
    1. 缓存过期请求及返回
    
    ```css
    # 请求
    If-Modified-Since: Fri, 26 Sep 2025 03:52:17 GMT 
    If-None-Match: "68d60df1-22"
    
    # 返回
    HTTP/1.1 304 Not Modified
    Last-Modified: Fri, 26 Sep 2025 03:52:17 GMT
    ETag: "68d60df1-22"
    Expires: Fri, 26 Sep 2025 05:53:45 GMT
    Cache-Control: max-age=60
    Cache-Control: public
    ```
    

# 页面缓存（服务器端缓存）

**概念**：nginx 缓存后端生成的动态页面或接口响应，减轻后端负载，加快响应。

- 方式一：**proxy_cache**（适合反向代理 API / HTML 页面）
- 方式二：**fastcgi_cache**（适合 PHP / FastCGI 服务）

---

### proxy_cache 示例

```css
proxy_cache_path /var/cache/nginx levels=1:2 keys_zone=mycache:10m max_size=1g inactive=60m use_temp_path=off;

server {
    location / {
        proxy_pass http://backend;
        proxy_cache mycache;
        proxy_cache_valid 200 10m;
        proxy_cache_valid 404 1m;
        add_header X-Cache-Status $upstream_cache_status;
    }
}
```

**`X-Cache-Status`** 含义

- **MISS**：表示 Nginx 代理缓存（proxy_cache）**没有命中**，请求是直接从后端获取的
- **HIT**：表示 Nginx 从缓存返回的响应，没有去后端
- **BYPASS**：缓存被忽略，没有缓存
- **EXPIRED**：缓存过期，需要重新向后端请求

### fastcgi_cache 示例

```css
fastcgi_cache_path /var/cache/nginx/fastcgi levels=1:2 keys_zone=phpcache:10m inactive=60m;

server {
    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        include fastcgi_params;
        fastcgi_cache phpcache;
        fastcgi_cache_valid 200 10m;
        add_header X-FastCGI-Cache $upstream_cache_status;
    }
}
```
