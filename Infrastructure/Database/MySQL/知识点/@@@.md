# @@@

> MySQL @ @@
> 

```bash
**@x 是 用户自定义的变量 (User variables are written as @var_name)
@@x 是 global或session变量 (@@global @@session ) 默认使用session**

show global variables like 'sort_buffer_size';
show session variables like 'sort_buffer_size';
show variables like 'sort_buffer_size';

set sort_buffer_size=131072;
set session sort_buffer_size=262144;
set global sort_buffer_size=262144;

select @@global.sort_buffer_size;
select @@session.sort_buffer_size;
select @@sort_buffer_size;

set @@global.sort_buffer_size=262144;
set @@session.sort_buffer_size=262144;
set @@sort_buffer_size=262144;
```
