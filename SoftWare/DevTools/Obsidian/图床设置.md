## Obsidian GitHub 图床设置

使用 GitHub 仓库作为 Obsidian（及各类 Markdown 编辑器）的免费图床。

### 核心步骤

1. **创建 GitHub 仓库**：新建公开仓库（如 `image-hosting`）
2. **生成 Personal Access Token**：Settings → Developer settings → Tokens，勾选 `repo` 权限
3. **配置 PicGo**：
   - 图床选择 GitHub
   - 仓库名：`用户名/仓库名`
   - 分支：`main`
   - Token：填入生成的 token
   - 存储路径：`img/`（可选自定义）
   - 自定义域名：`https://raw.githubusercontent.com/用户名/仓库名/main`
4. **Obsidian 集成**：
   - 安装 Image auto upload 插件
   - 设置默认上传工具为 PicGo
   - 粘贴图片即可自动上传并替换链接

### 优势

- 免费、无流量限制（GitHub 公开仓库）
- 兼容所有支持外部图片的 Markdown 编辑器
- 可配合 jsDelivr CDN 加速

### 注意

- 私有仓库图片链接无法直接访问。
- Token 需妥善保管，不要提交到公开仓库。
- GitHub 单文件限制 100MB，适合常规截图。
