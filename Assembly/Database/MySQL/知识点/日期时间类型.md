# 日期时间类型

# 概述

MySQL能存储的最小时间粒度为秒

# DATETIME

与时区无关

使用8个字节的存储空间

# TIMESTAMP

与时区有关，存储UTC时间

使用4个字节的存储空间

5.7版本，多个字段为 timestamp 时，都可以使用CURRENT_TIMESTAMP作为默认值，而且都可以根据当前时间戳更新

5.5-5.6.4版本 ，多个字段为timestamp时，只能有一个CURRENT_TIMESTAMP作为默认值，而且要在第一个timestamp类型字段设置。**如果当前的timestamp字段为非空的话默认是根据当时时间戳更新。**

```sql
`created_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
`updated_at` timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
`deleted_at` datetime NULL DEFAULT NULL,
```

# 时间转换

```bash
# 字符串转时间戳
UNIX_TIMETAMP()
# 时间戳转字符串 
FROM_UNIXTIME()
```

依赖于时区

??? 默认为非空

默认情况下，插入/修改 第一个TIMESTAMP列的值为当前时间

```bash
DEFAULT CURRENT_TIMESTAMP
DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
```

通常尽量使用TIMESTAMP

可以使用BIGINT类型存储微妙级别的时间戳，或者使用DOUBLE存储秒之后的部分

```bash
IPV4 unsigned int  
INET_ATON() 
INET_NTOA()
```
