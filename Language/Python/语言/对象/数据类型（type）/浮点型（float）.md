## 浮点型（float）

- 浮点实数最多可以精 确到 15 位小数
- `int` 和 `float` 型数值根据是否有小数点来区分， 如 2 是 int 型，而 2.0 是 float 型

```python
print(3*str(30)+"world") # 303030world
print(3*str(3.14))       # 3.143.143.14
print(3*str(3+6j))       # (3+6j)(3+6j)(3+6j)
```
