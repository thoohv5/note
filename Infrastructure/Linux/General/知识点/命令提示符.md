# 命令提示符

### 命令提示符参数

|  |  |  |
| --- | --- | --- |
| 序号 | 参数 | 含义 |
| 1 | \d | 代表日期，格式为weekday month date |
| 2 | \H | 完整的主机名称 |
| 3 | \h | 仅取主机的第一个名字(默认) |
| 4 | \t | 显示时间为24小时合适，如HH:MM:SS |
| 5 | \T | 显示时间为12小时格式 |
| 6 | \A | 显示时间为24小时格式 |
| 7 | \u | 当前用户的账号名称(默认) |
| 8 | \v | BASH的版本信息 |
| 9 | \w | 完整的工作目录名称。家目录会以~显示(默认) |
| 10 | \W | 利用basename取得工作目录名称，所以只会列出最后一个目录 |
| 11 | \# | 下达的第几个命令 |
| 12 | \$ | 提示字符，如果是root时，提示符为#，普通用户则为$ |

### 修改命令提示符(修改PS1变量)

路径： /etc/profile

```
# 命令提示符
export PS1='[\\u@\\h \\W]\\$'

# 改成自己的格式就行

```

#### 设置颜色

```
# 格式
\\[\\e[32;1m\\] 需要加颜色的内容 \\e[m

# 命令提示符 修改颜色
export PS1='\\[\\e[32;1m\\][\\u@\\h \\W]\\$\\e[m'

```

PS1中设置字符颜色的格式为：\[\e[F;Bm\]，其中“F“为字体颜色，编号为30-37，“B”为背景颜色，编号为40-47。用 \e[m 结束颜色设置，颜色表如下：

F 　　    B

30 　　 40 　　 黑色

31 　　 41 　　 红色

32 　　 42 　　 绿色

33 　　 43 　　 黄色

34 　　 44 　　 蓝色

35 　　 45 　　 紫红色

36 　　 46 　　 青蓝色

37 　　 47 　　 白色
