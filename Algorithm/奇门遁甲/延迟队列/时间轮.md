# 时间轮

时间轮核心算法思想：

任务放置到需要执行的时刻，然后等待时针转动到这个时刻，取出此时刻放置的任务，执行

时间轮的功能：

1. 加入任务
2. 执行任务
3. 删除任务
4. 沿着时间刻度前进

时间轮的实现：

1. 时间刻度链表+任务链表，每个任务上面增加属性round
2. 层级时间轮：任务从大轮到小轮的移动，表示任务临近执行时间，同时时间沿着时间刻度前进

操作系统：crontable

spring框架：quartz

java系统库：Timer和ScheduledThreadPoolExecutor

延迟队列：最小堆实现的优先级队列

插入一个任务的时间复杂度是O(logN),取出一个任务执行后调整堆的时间也是O(logN)
