# 脚本复用

## 执行方式不同效果不同

```
sh xxx.sh

```

当前进程中，新建子进程去执行，可以执行结果或输出

```
source xxx.sh 或 . xxx.sh

```

复制内容到当前进程中执行，可以获取执行结果或输出，定义的全局变量，定义的函数

## 导入模块

基于source或.的方式导入模块

系统会默认到$path中寻找导入文件

```bash
MODUPATH=$(dirname$(readlink -f $0))/module
echo${MODUPATH}
exportPATH=$PATH:${MODUPATH}

```

防止重复导入

```bash
if [${m_log} ];then
   return 0
fi
m_log="m_log"

```
