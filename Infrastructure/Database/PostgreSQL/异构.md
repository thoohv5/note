## 异构

## CDC数据集成

1. 捕获源数据库中的更改数据。
2. 将更改的数据转换为您的消费者可以接受的格式。
3. 将数据发布到消费者或目标数据库。

### PostgreSQL 提供了两种使 CDC 成为可能的内置方法：

- 来自 *事务日志、* PostgreSQL WAL，又名预写日志。
- *数据库触发器。*

## PostgreSQL逻辑解码

逻辑解码是 PostgreSQL 的基于日志的 CDC（逻辑复制）的正式名称

### Postgres配置文件 `postgresql.conf`

```sql
wal_level = logical
max_replication_slots = 5
max_wal_senders = 10
```

### 命令

```sql
## 创建复制槽
SELECT pg_create_logical_replication_slot('cdc_slot', 'wal2json');

## 删除复制槽
SELECT pg_drop_replication_slot('cdc_slot');

## 查询槽
SELECT slot_name, plugin, slot_type, database, active, restart_lsn, confirmed_flush_lsn FROM pg_replication_slots;

## 查询并删除数据
SELECT * FROM pg_logical_slot_get_changes('cdc_slot', NULL, NULL);

## 查询
SELECT * FROM pg_logical_slot_peek_changes('cdc_slot', NULL, NULL);
```

### 发布指定的表

```sql
CREATE PUBLICATION pub FOR ALL TABLES;
CREATE PUBLICATION pub FOR TABLE table1, table2, table3;
CREATE PUBLICATION insert_update_only_pub FOR TABLE table1 WITH (publish = 'INSERT, UPDATE');

SELECT * FROM pg_publication_tables WHERE pubname='pub'
```
