# 问题

```
connect: cannot assign requested address

```

### 查看

```
netstat -a|grep TIME_WAIT

netstat -ant|grep -i time_wait |wc -l

```

## 解决

```
vim /etc/sysctl.conf

net.ipv4.ip_forward=1
net.ipv4.tcp_tw_reuse = 1
net.ipv4.tcp_tw_recycle = 1

```

```
/sbin/sysctl -p

```
