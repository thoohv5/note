# 首字母转大小写

[https://blog.csdn.net/nakeer/article/details/118155113](https://blog.csdn.net/nakeer/article/details/118155113)

```
//LeftUpper 首字母转大写
func LeftUpper(s string) string {
   if len(s) > 0{
      return strings.ToUpper(string(s[0])) + s[1:]
   }
   return s
}

//LeftLower 首字母转小写
func LeftLower(s string) string {
   if len(s) > 0 {
      return strings.ToLower(string(s[0])) + s[1:]
   }
   return s
}
```
