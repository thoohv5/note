# SO_REUSEPORT

## `SO_REUSEPORT` 的切换规则：内核哈希算法

当你启动 V1 和 V2 共同监听端口时，切换规则是由 **Linux 内核** 硬编码的。

- **算法依据**：内核使用 `(源IP, 源端口, 目的IP, 目的端口)` 进行哈希计算。
- **分发规则**：
    - **静态分发**：对于同一个客户端连接，哈希值是固定的，流量会始终指向同一个 PID（这就是为什么 `wrk` 只命中 V2 的原因）。
    - **后进先出 (LIFO) 倾向**：在某些内核版本中，新加入的 Socket (V2) 会被放在监听列表的头部，因此新建立的连接有极高概率优先进入 V2。
- **切换触发点**：当你 `kill V1` 时，内核会将 V1 从哈希槽位中移除。
- **代价**：由于是内核暴力移除，如果此时有连接正在握手中（SYN 已收到但还没被 Accept），该连接可能会被重置。
