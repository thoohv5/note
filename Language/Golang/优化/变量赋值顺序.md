## 变量赋值顺序

> Go 赋值语句 `A, B = B, A` 先计算右侧表达式，再同时赋值给左侧，天然支持交换。

### 多重赋值

```go
a, b = b, a              // 交换
a, b, c = f()            // 多返回值
x, ok := m["key"]        // comma-ok 模式
```

### 赋值顺序细节

Go 规范保证：
1. 所有右侧表达式先求值
2. 然后从左到右赋值给左侧

```go
i := 0
i, s[i] = 1, 2  // i 先设为 1，然后 s[0]=2（i 在赋值前已被计算为 0）
```

### 常见陷阱

```go
// ❌ i++ 不是表达式
a, b = i++, i  // 编译错误

// ✅ 使用 i+1
a, b = i+1, i
```
