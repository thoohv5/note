# 概述

# 问题

```
# 执行SQL
select * from t_network;

# 报错
ERROR:  invalid page in block 26222 of relation base/16386/24873

```

# 定位

1. 检查POstgresSQL日志，查看相应的报错

```

# 损坏的库
select datname from pg_database where oid = 16386;

# 损坏表
select relname,relkind from pg_class where relfilenode = 24873;

损坏类型说明
r： 表示ordinary table（普通表）；
i： 表示index（索引）；
S： 表示sequence（序列）；
V： 表示view（视图）；
m： 表示materialized view（物化视图）；
c： 表示composite type（复合类型）;
t： 表示TOAST table（TOAST 表）；
f： 表示foreign table（外部表）

```

## 数据丢失场景

### 表数据损坏(r)

```
set zero_damaged_pages = on;
vacuum your_table;
reindex table idx_your_table;

```

### 表普通索引损坏(i)

```
set zero_damaged_pages = on;
reindex index idx_your_table;

```

### 表的主键或唯一键

```
set zero_damaged_pages = on;

alter table drop constriant yout_table_pkey;

alter table add constraint yout_table_pkey PRIMARY KEY (table_id);

```

### 元数据损坏

使用工具，从数据文件中读取数据 [[pg_filedump]]
