## 变量

变量是对象的引用:变量本身并不存储具体数值，它们仅是对象的引用。

变量名只能包含字母、数字和下画线，且不能以数字开头。同时，变量名不能和已经被 Python 语言使用的 名字(关键字)相同。

与静态类型语言不同，**Python 是一个动态类型语言，变量名仅是一个对象的名字，并不是占据 一块内存的那个对象本身，一个变量名可以随时指向不同的对象，直到程序运行时，才能根据其指 向的对象知道该对象的数据类型。**
