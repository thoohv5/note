## 硬件信息

## **查看网卡型号**

```bash
## **查看网卡型号**
**lspci | grep Ethernet**
```

## **查看内存**

```bash
**# 查看内存
free
cat /proc/meminfo**
```

## **查看CPU**

```bash
**# 查看CPU
 cat /proc/cpuinfo**
```

## **查看硬盘信息（查看硬盘型号和硬盘序列号）**

```bash

**# 查看硬盘信息（查看硬盘型号和硬盘序列号）
df -h
hdparm -i /dev/sda
dmesg | grep ATA
dmidecode|more**
```

## How to display information about the CPU on Linux
