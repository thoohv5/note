# 对象

类型和编码

```c
# 类型
> type name

# 编码
> object encoding name
```

基于引用计数技术的内存回收机制，当程序不再使用某一个对象的时候，这个对象多占用的内存就会被自动释放

字符串对象的编码

int、raw或者embstr

列表对象的编码

ZipList、LinkedList

> 因此Redis3.2版本开始对列表数据结构进行了改造，使用 Quicklist 代替了 ZipList 和 LinkedList.
> 

哈希对象的编码

ZipList、HashTable

集合对象的编码

Intset、HashTable

有序集合的编码（HashTable）

ZipList、SkipList
