## 格式化

### format

PostgreSQL 的 `format()` 函数类似 C 语言 `sprintf`，用于格式化字符串。

```sql
-- 语法
format(formatstr, formatarg [, ...])

-- %s: 字符串字面量  %I: SQL 标识符（自动加双引号）
-- %L: SQL 字面量（自动加单引号和转义）  %%: 纯百分号
```

### 示例

```sql
-- 安全拼接标识符
SELECT format('SELECT * FROM %I.%I WHERE %I = %L',
             'public', 'users', 'status', 'active');
-- => SELECT * FROM public.users WHERE status = 'active'

-- 动态列名
SELECT format('INSERT INTO %I (%s) VALUES (%s)',
             'mytab', 'a, b, c', '1, 2, 3');
-- => INSERT INTO mytab (a, b, c) VALUES (1, 2, 3)
```

### 主要用途

- 动态 SQL 拼接时防止 SQL 注入（`%I` / `%L` 自动转义）
- 与 `EXECUTE` 配合实现函数内动态查询

### 注意事项

- `%I` 把参数视为标识符，`.`` 不视为分隔符；如需 `schema.table` 要将各部分分别 `%I` 处理
- 性能：对于静态 SQL 仍推荐直接拼接常量，`format()` 仅用于真正需要动态构建的场景
