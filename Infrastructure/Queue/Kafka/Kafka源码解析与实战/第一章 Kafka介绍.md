# 第一章 Kafka介绍

# 概述

Kafka诞生的背景、Kafka在LinkedIn内部的应用、Kafka的主要设计目标以及为什么使用消息系统

# Kafka诞生的背景

管理从各个应用程序汇聚到此的信息流，这些数据经过处理后再被分发到各处。

理想情况下，生产者或消费者应该只与一个数据源单独集成，这样就能访问到所有数据。

# Kafka在LinkedIn内部的应用

- 系统监控
- 传统消息队列
- 分析
- 作为其他分布式日志系统的组件
- MorrorMaker
- RESTful接口
- 审计服务

# Kafka的主要设计目标

Kafka作为一种分布式的、基于发布/订阅的消息系统，其主要设计目标：

- O(1)时间复杂度的消息持久化能力 (支持TB级)
- 高吞吐率 (支持单机100K/s)
- 支持消息分区、以及分布式消费，同时保准每一个分区的消息顺序传输
- 支持离线数据处理和实时数据处理
- 支持在线水平扩展

# 为什么使用消息系统

- 解耦
- 限流/削峰
- 异步
- 扩展性
- 顺序性
- 冗余
