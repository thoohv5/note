## 查看汇编

```go
// 编译不内联
go tool compile -N -l main.go
// 查看汇编
go tool objdump main.o

// 查看汇编
go build -gcflags '-m -l' main.go

// 查看汇编
go tool compile -N -l -S main.go

```
