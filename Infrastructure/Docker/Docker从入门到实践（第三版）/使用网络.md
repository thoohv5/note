# 使用网络

## 外部访问

当使用 -P 标记时，Docker 会随机映射一个 49000~49900 的端口到内部容器开放的网络端口。

## 容器互联

### 新建网络

格式：`docker network create -d bridge my-net`

参数：

- `-d` 参数指定 `Docker` 网络类型，有 `bridge`、`overlay`

### 连接容器

格式：`docker run -it --rm --name busybox1 --network my-net busybox sh`
