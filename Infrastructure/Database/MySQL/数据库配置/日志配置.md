# 日志配置

## **配置位置**

```
mysql --help|grep 'my.cnf'
mysqld --help --verbose |grep -A 1 'Default options';
```

## 全查询日志

```
log=/data/mysql/query.log
```

报错：

```
Starting MySQL... ERROR! The server quit without updating PID file (/data/mysql/mysql.pid).
```

原因是5.7版本的日志配置方法改变了

```
general_log=ON
general_log_file=/data/mysql/query.log
```

## 错误日志

```
log-error=/data/mysql/error.log
```

## 慢查询日志

```
slow_query_log=on
log_queries_not_using_indexes=on // 记录不使用索引的sql
long_query_time =0.01    #慢于0.01秒的会被记录
# 如果没有为慢查询日志文件指定名称，则默认名称为 host_name-slow.log
slow_query_log_file=/data/mysql/slowquery.log
```

## 二进制日志

### 格式

```bash
# STATMENT, 基于语句的日志格式，基于语句的复制（SBR）
binlog_format=STATMENT

#ROW，基于行的日志格式，基于行的复制（RBR）
binlog_format=ROW
binlog_row_image=[FULL|MINIMAL|NOBLOD]

#MIXED，混合的日志格式
binlog_format=MIXED
```

### 配置

```

#二进制日志配置，第二、三行配置最后一个binlog-bin和binlog是不加后缀的文件名，不加后缀的话有妙用  
server-id=1  
log_bin=/data/mysql//log_bin/binlog-bin 
log_bin_index=/data/mysql/log_bin/binlog
```

## 配置的验证

```
show variables like "log%";
```

### mysql slow log explain

方式一

mysqldumpslow

```
mysqldumpslow -s at -t 10 /data/mysql/data/mysql-slow.log|more
```

方式二

pt_query-digest

```
pt_query-digest /data/mysql/data/mysql-slow.log|more
```
