### 启动容器

### 新建并启动

格式：`docker run [选项] 仓库名[:标签] bash`

选项：

- `-i` 交互式操作
- `-t` 终端
- `—rm` 退出后删除容器
- `-d` 后台运行

**启动操作流程**

- 检查本地是否存在指定的镜像，不存在就从公有仓库下载
- 利用镜像创建并启动一个容器
- 分配一个文件系统，并在只读的镜像层外面挂载一层可读写层
- 从宿主主机配置的网桥接口中桥接一个虚拟接口到容器中去
- 从地址池配置一个 ip 地址给容器
- 执行用户指定的应用程序
- 执行完毕后容器被终止

### 启动已终止容器

格式：`docker container start [container ID or NAMES]`

### 日志查看

格式：`docker container logs [container ID or NAMES]`

```docker
## 容器列表
ocker container ls

## 指定容器日志

```

### 终止容器

格式：`docker container stop [container ID or NAMES]`

### 进入容器

### **`attach`命令**

格式：`docker attach [container ID or NAMES]`

<aside>
💡

> 如果从这个 stdin 中 exit，会导致容器的停止。
> 
</aside>

### **`exec`命令**

格式：`docker exec [选项] [container ID or NAMES]`

选项：

- `-i` 交互式操作
- `-t` 终端

<aside>
💡

如果从这个 stdin 中 exit，不会导致容器的停止。【推荐使用】

</aside>

### 导出容器

格式：`docker export [container ID or NAMES] > xxx.tar`  

### 导入容器

格式：`docker import xxx.tar 仓库名[:标签]`

### 删除容器

格式：`docker rm [container ID or NAMES]`

### 清理所有处于终止状态的容器

```docker
## 清理掉所有处于终止状态的容器
docker container prune
```
