# 向量数据库（VectorDB）

# 基本概念

## 向量（Vector）

多维数学空间中的一个坐标点

### 向量类型（Vector Type）

**图形向量**
通过神经网络模型是取图像特征向量Feature Map,特征向量Feature Map提取输入图像的高维信息，如颜色、形状、纹理等，最终可以用于图像识别、检索等任务：
**文本向量**
通过词嵌入Word Embeding如word2ec,BERT等生成文本特征向量，文本特征向量包含文本语义高维信息，可以用于文本分类、情感分析等NLP任务；
**语音向量**
通过声学模型Acoustic Model从音频信号中提取的音频的频谱特征向量，频谱特征向量提取声音的高维特性，如音调、节奏、音色等，可用于语音识别、声纹识别等任务：
