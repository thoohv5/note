## 查找搜索类

### **使用场景**

| 命令 | 查找方向 | 适用场景 | 优缺点 |
| --- | --- | --- | --- |
| [[find]] | 指定目录及递归搜索子目录 | 查找某一类文件 | 功能强大 速度慢 |
| [[locate]] | /var/lib/mlocate/mlocate.db数据库 | 只能查找单个文件 | 功能单一,速度快 |
| [[whereis]] | /var/lib/mlocate/mlocate.db数据库 | 查询程序的可执行文件,帮助文档等 |  |
| [[which]] | $PATH下查找 | 查找程序的可执行文件 | 常用于查找程序的绝对路径 |
|  |  |  |  |
