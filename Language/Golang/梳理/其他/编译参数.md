# 编译参数

### `-x -v`

- -v 用于输出当前正在编译的包
-x 用于输出build执行的每一个命令

```go
go build -x -v ./...
```

### `-race`

- `-race` 开启竞争检查，在程序运行时，如果发现对数据的并发禁止访问，就会给出告警。

```go
go run -race main.go
```

### `-gcflags`

传递给编译器的标志选项集合

```go
go tool compile -help
```

- -`l：关闭内敛。`
- -`N：关闭代码优化。`
- -`m：输出逃逸分析的分析决策过程（哪些变量在栈上分配，哪些变量在堆上分配）。`
- -`S：输出汇编代码。`

```go
go build -gcflags='空格分割的标志选项列表'

go build -gcflags='-l -m' ./...

```

### `-ldflags`

传给连接器的标志选项集合

```go
go tool link -help
```

- `-X: 设定包中string类型变量的值。`
- `-s: 不生成符号表。`
- `-w: 不生成DWARF（Debugging With Attributed Record Formats）调试信息。`

```go
go build -ldflags="-X main.version=v0.1" ./...
```
