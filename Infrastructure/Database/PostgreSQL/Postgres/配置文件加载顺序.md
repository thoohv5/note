## 配置文件加载顺序

```

## 默认的全局配置文件
PostgreSQL安装目录/data/postgresql.conf
PostgreSQL安装目录/data/postgresql.auto.conf

## 如果使用-D或者--pgdata指定自定义的数据目录
PostgreSQL数据目录/postgresql.conf

## 个人配置 ~/.postgresql/postgresql.conf

加载顺序：后面加载的配置文件回覆盖前面加载的配置文件中的相同配置

## 重新加载配置
pg_ctl reload
psql -c "SELECT pg_reload_conf();"

```
