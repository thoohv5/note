## 数据库/表/索引/表空间

## 数据库

```sql
## 查看所有数据库
\l
## 查看所有数据库的大小
select pg_database.datname, pg_database_size(pg_database.datname) AS size from pg_database;
## 单个数据库大小
select pg_database_size('database');
## 以KB，MB，GB的方式来查看数据库大小
select pg_size_pretty(pg_database_size('hwb'));
```

## 表

```sql
## 当前数据库下所有表
\d
## 表定义
\d table
## 查看test表大小
select pg_relation_size('table');
## 以KB，MB，GB的方式来查看表大小
select pg_size_pretty(pg_relation_size('table'));
## 查看表的总大小，包括索引大小
select pg_size_pretty(pg_total_relation_size('table'));
```

## 索引

```sql
## 查看当前数据库所有索引
\di
## 查看单个索引大小
select pg_size_pretty(pg_relation_size('parent_pkey'));
```

## 表空间

```sql
## 查看所有表空间
select spcname from pg_tablespace;
## 查看表空间大小
select pg_size_pretty(pg_tablespace_size('pg_default'));
```
