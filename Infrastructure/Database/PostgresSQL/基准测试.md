# 基准测试

# 目标

```bash
What type of workload?
How many concurrent sessions?
What is the average result set of queries?
What are the expected tps(transaction per sec)?
```

# 测试

```bash
# TPC-B测试模型的初始化数据参数.
Initialization options:
# 初始化参数
-i invokes initialization mode
-F NUM fill factor
-n do not run VACUUM after initialization
-q quiet logging (one message each 5 seconds)
-s NUM scaling factor
--foreign-keys  create foreign key constraints between tables
-index-tablespace=TABLESPACE create indexes in the specified tablespace
--tablespace=TABLESPACE  create tables in the specified tablespace
--unlogged-tables create tables as unlogged tables
 
# 压力测试相关参数
Benchmarking options:
# 指定pgbench连接到数据库的连接数
-c NUM number of concurrent database clients (default: 1)
# 是否使用短连接
-C establish new connection for each transaction
# 设置变量, 在自定义脚本中使用:varname 引用. 可使用多个-D设置多个变量
-D VARNAME=VALUE
# 指定自定义的测试文件(由元命令和SQL组成), 可使用多个-f 指定多个文件, 每个文件作为一个事务, 每次执行事务时随机选择一个文件执行
-f FILENAME read transaction script from FILENAME
# pgbench的工作线程. 为-c一起用；为-c的约数
-j NUM number of threads (default: 1)
# 开启事务统计, 输出文件名格式pgbench_log.$PID.$threadID , (当-j >= 2时, threadID从1开始)
-l write transaction times to log file
# libpq接口  default: simple
-M simple|extended|prepared
# vacuum开关, 使用自定义文件时, 使用-n关闭vacuum
-n do not run VACUUM before tests
# TPC-B 非默认测试模式, 少两个表的更新
-N do not update tables "pgbench_tellers" and "pgbench_branches"
# 报告测试文件中每条命令(包括元命令和SQL)的平均执行延迟
-r report average latency per command
# 使用自定义脚本测试时, 指定scale的输出. 没有实质意义
-s NUM report this scale factor in output
# TPC-B 非默认测试模式, 只查询
-S perform SELECT-only transactions
# 指定每个连接的执行事务数
-t NUM number of transactions each client runs (default: 10)
# 指定总的压力测试时间. 与-t不能同时使用
-T NUM duration of benchmark test in seconds
# 测试前先vacuum 4个和tpc-b相关的表
-v vacuum all four standard tables before tests
# 输出聚合后的事务统计信息. 与-l连用
--aggregate-interval=NUM
 
# Common options:
  -d, --debug              print debugging output
  -h, --host=HOSTNAME      database server host or socket directory
  -p, --port=PORT          database server port number
  -U, --username=USERNAME  connect as specified database user
  -V, --version            output version information, then exit
  -?, --help               show this help, then exit
```

```bash
# 数据初始化, s:默认数据(10W)的倍数
psql -Upostgres -p5432 -c"create database pgbench;";
pgbench -i -s2 -Upostgres -p5432 -d pgbench

# 100个用户，每个用户10个事务
pgbench -c 100 -t 10 -Upostgres -p5432 -d pgbench

# 500个用户，每用户5个事务，4线程并发处理
pgbench -c 500 -t 5 -j 4 -Upostgres -p5432 -d pgbench

# 1个用户，10s压力测试时间，每条SQL平均执行延迟
pgbench -c 1 -T 20 -r -Upostgres -p5432 -d pgbench
```
