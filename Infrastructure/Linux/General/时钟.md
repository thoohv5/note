# 时钟

# 概述

在Linux下，默认情况下，系统时钟和硬件时钟，并不会自动同步。在Linux运行过程中，系统时间和硬件时间以异步的方式运行，互不干扰。硬件时间的运行，是靠Bios电池来维持，而系统时间，是用CPU tick来维持的。

在系统开机的时候，会自动从Bios中取得硬件时间，设置为系统时间。

# 分类

## 硬件时钟（RTC）

- **位置：** 硬件时钟通常集成在计算机的主板上。
- **特点：** 持续运行，即使计算机关机也能保持计算机的时间。
- **用途：** 用于提供计算机在关机状态下的实时时间。硬件时钟的时间是相对稳定的，不受计算机启动和关机的影响。
- **操作：** 使用命令 `hwclock` 可以访问和管理硬件时钟，包括读取、设置、同步硬件时钟和系统时钟之间的时间。

## 系统时钟

- **位置：** 系统时钟是操作系统内部的一个计时器，通常在计算机启动时由硬件时钟初始化。
- **特点：** 会在计算机启动时从硬件时钟中读取时间，并在运行过程中动态更新。
- **用途：** 用于跟踪系统的运行时间，提供给操作系统和应用程序使用。
- **操作：** 使用命令 `date` 和 `timedatectl` 可以访问和管理系统时钟，包括查看和设置系统时间、时区，以及进行时间同步操作。
