# 厦大

1. 备份slave ipam.db的数据【172.18.0.13】
    
    ```bash
    cp /usr/local/zddi/ipam.db /tmp/ipam_13.db
    # 通过ftp保存到本地
    ```
    
2. slave导出网络地址数据
    
    ```bash
    sqlite3 /usr/local/zddi/ipam.db ".dump usablenetwork" > usablenetwork.sql
    # 通过ftp保存在本地
    ```
    
3. 上传slave的网络数据到master
    
    ```bash
    #通过ftp上传到master
    ```
    
4. 备份master ipam.db的数据【172.18.0.12】
    
    ```bash
    cp /usr/local/zddi/ipam.db /tmp/ipam_12.db
    # 通过ftp保存到本地
    ```
    
5. 删除master 的网络地址表
    
    ```bash
    sqlite3 /usr/local/zddi/ipam.db "drop table usablenetwork"
    ```
    
6. 导入slave网络数据到master的ipam.db
    
    ```bash
    sqlite3 /usr/local/zddi/ipam.db < usablenetwork.sql
    ```
    
7. 重启服务
