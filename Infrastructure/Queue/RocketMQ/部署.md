# 安装部署

```yaml
services:

  rmqnamesrv:
    image: apache/rocketmq:5.3.2
    container_name: rmqnamesrv
    ports:
      - 9876:9876
    networks:
      - thooh
    command: sh mqnamesrv

  rmqbroker:
    image: apache/rocketmq:5.3.2
    container_name: rmqbroker
    ports:
      - 10909:10909
      - 10911:10911
      - 10912:10912
    environment:
      - NAMESRV_ADDR=rmqnamesrv:9876
    volumes:
      - ./broker.conf:/home/rocketmq/conf/broker.conf
    depends_on:
      - rmqnamesrv
    networks:
      - thooh
    command: sh mqbroker -c /home/rocketmq/conf/broker.conf

  rmqproxy:
    image: apache/rocketmq:5.3.2
    container_name: rmqproxy
    depends_on:
      - rmqbroker
      - rmqnamesrv
    ports:
      - 8080:8080
      - 8081:8081
    restart: on-failure
    environment:
      - NAMESRV_ADDR=rmqnamesrv:9876
    networks:
      - thooh
    command: sh mqproxy

  rmqdashboard:
    image: apacherocketmq/rocketmq-dashboard:latest
    container_name: rmqdashboard
    ports:
      - "8089:8080"
    environment:
      - JAVA_OPTS=-Drocketmq.namesrv.addr=rmqnamesrv:9876
    depends_on:
      - rmqnamesrv
    networks:
      - thooh

#networks:
#  rocketmq:
#    driver: bridge
networks:
  thooh:
    external: true
```

## 🧩 RocketMQ Proxy 的作用

### 1. **支持多语言客户端**

RocketMQ 原生客户端（例如 Java）通过 **TCP 协议（Remoting Protocol）** 与 Broker 通信。但对于非 Java 语言（如 Go、Python、C++）：

- 官方 SDK 使用的是 **gRPC + HTTP/2 协议**
- 这些 SDK 无法直接连接 broker
- 所以必须通过 **Proxy** 转发请求

👉 **Proxy 就是 “非 Java 客户端” 和 RocketMQ 的中间桥梁**

---

### 2. **简化网络部署**

Proxy 可作为 **边车（Sidecar）/中间层** 部署：

- 不需要暴露 Broker 给所有客户端
- 降低了对客户端网络配置的要求
- 支持集群代理部署（多 Proxy + 负载均衡）

---

### 3. **安全隔离与接入控制**

通过 Proxy，你可以：

- 设置统一的认证、鉴权策略（如 AccessKey）
- 控制流量入口（例如只开放 Proxy，隐藏 Broker）

---

## 📌 一句话总结

> rocketmq-proxy 是面向 Go、C++、Python 等非 Java 客户端的 RocketMQ 网关组件，客户端必须通过它来访问 RocketMQ（使用 gRPC 协议）。
