# 约定和惯例

1. 可见性规则
    - 标识符以大写字母开头，则对外包可见
    - 标识符以小写字母开头，则对包外不可见的，但是包内可见
    - 包名不管在什么情况下都必须小写
2. 命名规范以及语法惯例
    1. 包名在源文件中第一行通过关键字package指定，包名要小写
    2. 在定义接口名时也有惯例，一般单方法接口由方法名称加上-er后缀来命名
    3. 函数或方法的注释需要以函数名开始，且两者之间没有空行, 需要预格式化的部分，直接加空格缩进即可

按照惯例， 包应当以小写的单个单词来命名，且不应使用下划线或驼峰记法。

包名应为其源码目录的基本名称

大写字母即为可导出

按照约定，只包含一个方法的接口应当以该方法的名称加上-er后缀或类似的修饰来构造一个施动着名词，如 Reader、Writer、 Formatter、CloseNotifier 等。

请将字符串转换方法命名为 String 而非 ToString。

Go中约定使用驼峰记法 MixedCaps 或 mixedCaps
