## 绝对路径

## **`os.Executable()`**

**`os.Executable()`** 是 Go 语言标准库 **`os`** 提供的函数，用于获取 **当前正在运行的可执行文件（executable）的绝对路径**。它的行为类似于 Linux 的 **`readlink /proc/self/exe`** 或 Windows 的 **`GetModuleFileName`**。

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	exePath, err := os.Executable()
	if err != nil {
		fmt.Println("获取可执行文件路径失败:", err)
		return
	}
	fmt.Println("可执行文件路径:", exePath)
}

/**
❯ go run ./golang/work-dir/executable/main/main.go

❯ go run /Users/thooh/Sites/github.com/thoohv5/devops/golang/work-dir/executable/main/main.go
可执行文件路径: /var/folders/sr/ygvxzfnn4nl3dr28cwxs46640000gn/T/go-build756290407/b001/exe/main

❯ go build ./golang/work-dir/executable/main/main.go

```

<aside>
💡

**`os.Executable()`** 解析符号链接，返回实际路径。

</aside>

## `os.Getwd()`

**`os.Getwd()`** 是 Go 语言标准库 **`os`** 提供的函数，用于获取 **当前工作目录（Current Working Directory, CWD）** 的绝对路径。它的行为类似于 Linux/macOS 的 **`pwd`** 命令或 Windows 的 **`cd`**（不带参数）。

工作目录是指 **运行程序时所在的目录**，而不是程序本身的存放位置。

```go
package main

import (
	"fmt"
	"os"
)

// /Users/thooh/Sites/github.com/thoohv5/devops/golang/work-dir/wd/main/main.go
func main() {
	// 工作目录
	wd, err := os.Getwd()
	if err != nil {
		fmt.Println("Error getting working directory:", err)
		return
	}
	fmt.Println("Working directory:", wd)

	// 改变工作目录
	newWd := "/tmp"
	if err := os.Chdir(newWd); err != nil {
		fmt.Println("Error changing working directory:", err)
		return
	}

	// 工作目录
	wd, err = os.Getwd()
	if err != nil {
		fmt.Println("Error getting new working directory:", err)
		return
	}
	fmt.Println("New working directory:", wd)
}

/**
❯ go run ./golang/work-dir/wd/main/main.go
Working directory: /Users/thooh/Sites/github.com/thoohv5/devops
New working directory: /private/tmp

❯ go run /Users/thooh/Sites/github.com/thoohv5/devops/golang/work-dir/wd/main/main.go
Working directory: /Users/thooh/Sites/github.com/thoohv5/devops
New working directory: /private/tmp

❯ go build ./golang/work-dir/wd/main/main.go
❯ ./main
Working directory: /Users/thooh/Sites/github.com/thoohv5/devops
New working directory: /private/tmp
*/
```

<aside>
💡

### **受 `os.Chdir()` 影响**

如果程序内部调用了 **`os.Chdir()`** 修改工作目录，后续 **`os.Getwd()`** 会返回新目录

</aside>

## **区别对比**

### **路径类型**

- **`os.Executable()`** → **绝对路径**（程序自身）
- **`os.Args[0]`** → **用户输入的路径**（可能是相对路径）
- **`os.Getwd()`** → **当前 Shell 目录**（绝对路径）

### **符号链接处理**

- **`os.Executable()`** 解析符号链接，返回实际路径。
- **`os.Args[0]`** 直接返回符号链接名称。

### **典型问题**

```bash
## 假设:
## - 程序路径: /usr/local/bin/myapp
## - 符号链接: /usr/bin/myapp → /usr/local/bin/myapp
## - 当前目录: /tmp
## 运行命令:
$ cd /tmp
$ /usr/bin/myapp
```

| **函数** | **返回值** | **说明** |
| --- | --- | --- |
| **`os.Executable()`** | **`/usr/local/bin/myapp`** | 实际路径 |
| **`os.Args[0]`** | **`/usr/bin/myapp`** | 用户输入的符号链接路径 |
| **`os.Getwd()`** | **`/tmp`** | Shell 当前目录 |

## 文件绝对路径

```go
package path

import (
	"fmt"
	"io/ioutil"
	"os"
	spath "path"
	"path/filepath"
	"runtime"
	"strings"

	"github.com/pkg/errors"
)

var (
	ErrPathRead       = errors.New("path read err")
	ErrFileDelete     = errors.New("file delete err")
	ErrFileExecutable = errors.New("file executable err")
	ErrFileSymlinks   = errors.New("file symlinks err")
)

// CurrentAbPath 当前绝对路径
func CurrentAbPath(opts ...Option) (string, error) {

	// 参数拆解
	o := &options{}
	for _, opt := range opts {
		opt(o)
	}

	// 当前执行文件绝对路径
	dir, err := CurrentAbPathByExecutable()
	if nil != err {
		return "", err
	}

	// 临时目录
	tDir, err := tmpDir()
	if nil != err {
		return "", nil
	}

	// 是否为go run场景
	if strings.Contains(dir, tDir) {
		// 当前执行文件绝对路径
		return CurrentAbPathByCaller(opts...), nil
	}

	return dir, nil
}

// 获取系统临时目录，兼容go run
func tmpDir() (string, error) {
	dir := os.Getenv("TEMP")
	if dir == "" {
		dir = os.Getenv("TMP")
	}

	// 绝对路径
	res, err := filepath.EvalSymlinks(dir)
	if nil != err {
		err = errors.WithMessagef(ErrFileSymlinks, "err:%v", err)
		return "", err
	}

	return res, nil
}

// CurrentAbPathByExecutable 当前执行文件绝对路径
func CurrentAbPathByExecutable() (string, error) {

	// 执行文件
	exePath, err := os.Executable()
	if err != nil {
		err = errors.WithMessagef(ErrFileExecutable, "err:%v", err)
		return "", err
	}

	// 绝对路径
	res, err := filepath.EvalSymlinks(filepath.Dir(exePath))
	if err != nil {
		err = errors.WithMessagef(ErrFileSymlinks, "err:%v", err)
		return "", err
	}

	return res, nil
}

// CurrentAbPathByCaller 当前执行文件绝对路径
func CurrentAbPathByCaller(opts ...Option) string {
	o := &options{}
	for _, opt := range opts {
		opt(o)
	}
	var abPath string
	_, filename, _, ok := runtime.Caller(o.skip)
	if ok {
		abPath = spath.Dir(filename)
	}
	return abPath
}

// AbPath 获取绝对路径
func AbPath(file string, opts ...Option) string {

	// 参数解析
	o := &options{
		file: file,
		skip: 2,
	}
	for _, opt := range opts {
		opt(o)
	}

	// 绝对路径
	return fmt.Sprintf("%s/%s", CurrentAbPathByCaller(opts...), o.file)
}

// Rm 删除文件夹，不包括当前文件夹
func Rm(path string) (err error) {
	dir, err := ioutil.ReadDir("/tmp")
	if nil != err {
		err = errors.WithMessagef(ErrPathRead, "err:%v", err)
		return
	}
	for _, d := range dir {
		if err = os.RemoveAll(spath.Join([]string{"tmp", d.Name()}...)); nil != err {
			err = errors.WithMessagef(ErrFileDelete, "err:%v", err)
			return
		}
	}
	return
}
```
