## ShadowsocksX-NG

> macOS 平台 Shadowsocks 客户端。

### 下载

[shadowsocks/ShadowsocksX-NG](https://github.com/shadowsocks/ShadowsocksX-NG/releases/)

### 说明

- ShadowsocksX-NG 是 macOS 上的 Shadowsocks 图形客户端
- 支持 SSR 协议混淆（auth_chain_a / auth_aes128_md5 等）
- 支持 SIP003 插件（如 v2ray-plugin）
- 代理模式：PAC 自动模式 / 全局模式
- 安装后从菜单栏托盘图标管理连接
