## 分隔函数

### SPLIT_PART

```sql
SPLIT_PART(string, delimiter, position)
```

- string 待分隔的字符串
- delimiter 指定分隔的字符串
- position 第几个子串，从1开始，必须为正数

### string_to_array

```sql
string_to_array(string, delimiter [, null string])
```

- string 待分隔的字符串
- delimiter 指定分隔的字符串
- null string 等同`unnest`移除指定子串

### regexp_split_to_array

```sql
regexp_split_to_array ( string text, pattern text [, flags text ] ) → text[]

SELECT regexp_split_to_array('foo  bar baz', '\s+');
SELECT t as item FROM regexp_split_to_table('foo    bar,baz', E'[\\s,]+') AS t;
```

### regexp_matches

```sql
regexp_matches

regexp_matches('hello how are you', 'h[a-z]*', 'g')
```
