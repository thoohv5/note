## Obsidian

> 基于本地 Markdown 文件的知识管理和笔记工具。

### 核心特性

| 特性 | 说明 |
|------|------|
| 本地优先 | 笔记以 .md 文件存储在本地 |
| 双向链接 | `[[note]]` 语法，自动追踪引用 |
| 图谱视图 | 笔记关系的可视化 |
| 插件生态 | 大量社区插件扩展功能 |
| 模板系统 | 可自定义笔记模板 |
| Canvas | 无限画布，拖拽组织笔记 |

### 插件推荐

- **Obsidian Git**：自动 git 备份
- **Excalidraw**：手绘风格图表
- **Dataview**：将笔记作为数据库查询
- **Templater**：高级模板功能
- **Calendar**：日历视图管理日记
