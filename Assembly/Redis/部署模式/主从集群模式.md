# 主从集群模式

![](https://raw.githubusercontent.com/thoohv5/ob/main/pictureredis部署模式-主从集)A4.drawio.png

主从集群，主从库之间采用的是读写分离
主库：所有的写操作都在主库发生，然后主库同步数据到从库，同时也可以进行读写操作
从库：只负责读操作

## 全量同步

条件：

1. 从服务器首次加入主服务器
2. SAVEOF on one

![](https://raw.githubusercontent.com/thoohv5/ob/main/picture202312291548000.png)

步骤：

1. 从服务器 `psync ? -1` 质询主服务器的 `run ID` 和 `offset`
2. 主服务器 `+FULLRESYNC {run ID} {offset}` 回复从服务器 run ID 和 offset
3. 从服务器保存信息
4. 主服务器 `send RDB` 主动发送RDB文件给从服务器，同步依赖`RDB` 文件，主库会通过`bgsave`命令，生成`RDB` 文件，然后将`RDB` 文件传送到从服务器中。
5. 主服务器 `send buffer` 主动发送缓冲文件给从服务器
6. 从服务器 `flush old data` 清除自己的数据
7. 从服务器 `load RDB` 加载 `RDB`
8. 从服务器 `bgrewriteaof` 加载缓冲文件

备注：

1. 是否开启RDB和AOF与能否建立主从复制无关
