# 笔记属性标准

## 属性格式 (YAML Frontmatter)

```yaml
---
tags: [tag1, tag2]
date: 2024-01-01
type: note|guide|reference|cheatsheet
status: incomplete|complete|review
related: [[相关笔记名称]]
---
```

## 属性说明

| 属性        | 必填  | 说明         | 示例                                                                  |
| --------- | --- | ---------- | ------------------------------------------------------------------- |
| `tags`    | 可选  | 标签，用于分类和检索 | `[go, concurrency, goroutine]`                                      |
| `date`    | 可选  | 创建日期       | `2024-01-01`                                                        |
| `type`    | 可选  | 笔记类型       | `note`(笔记) <br>`guide`(指南) <br>`reference`(参考) <br>`cheatsheet`(速查) |
| `status`  | 可选  | 完成状态       | `incomplete`(未完成) <br>`complete`(已完成) <br>`review`(待复习)             |
| `related` | 可选  | 关联笔记       | `[[相关笔记]]`                                                          |
|           |     |            |                                                                     |

## 双向链接

- 使用 `[[wiki链接]]` 创建链接
- Obsidian 会自动生成反向链接
- 可在 `related` 字段手动指定关联笔记
