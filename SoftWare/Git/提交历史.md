## Git 查看提交历史

`git log` 是最常用的查看提交历史命令，支持丰富的过滤和格式化选项。

### 基本用法

```bash
git log                     # 查看完整历史
git log --oneline           # 单行摘要
git log -3                  # 最近 3 条
git log --since="2 weeks ago"  # 时间过滤
git log --author="John"     # 按作者过滤
git log --grep="fix"        # 按提交信息搜索
git log -S "function_name"  # 按代码变更搜索
```

### 格式化输出

```bash
git log --pretty=format:"%h - %an, %ar : %s"
# %h  短哈希
# %an 作者名
# %ar 相对日期
# %s  提交标题

git log --graph --oneline --decorate --all
# 图形化分支历史
```

### 文件相关

```bash
git log -- file.txt         # 特定文件历史
git log -p file.txt         # 显示每次 diff
git log --stat              # 显示统计信息
git log -L :func:file.go   # 追踪函数变更
```

### 区间查询

```bash
git log main..feature       # feature 有但 main 没有的
git log HEAD~3..HEAD        # 最近 3 个提交
```
