## location 匹配规则

## 语法规则

```sql
location [=|~|~*|^~] /uri/ { … }
```

### 说明

- `=` 表示精确匹配;
- `^~` 表示uri以某个常规字符串开头，理解为匹配 url路径即可;
- `~` 表示区分大小写的正则匹配;
- `~*`表示不区分大小写的正则匹配 ;
- `!~和!~*`分别为区分大小写不匹配及不区分大小写不匹配 的正则;
- `/` 通用匹配，任何请求都会匹配到。
