# ps

进程状态：

### R (Running)

进程正在运行或在运行队列中等待执行。

### S (Sleeping)

进程处于休眠状态，即正在等待某个事件的发生。这可能是等待IO、等待信号、等待锁等。

### D (Disk Sleep)

进程处于不可中断的休眠状态，通常是在等待磁盘IO。这种状态下进程不会响应信号，只能通过重新启动系统或者杀死该进程来解决。

### T (Stopped)

进程被暂停（停止），通常是由于收到了 `SIGSTOP`、`SIGTSTP`、`SIGTTIN` 或 `SIGTTOU` 信号。可以通过发送 `SIGCONT` 信号来继续运行。

### Z (Zombie)

进程已经终止，但其父进程还没有通过 `wait` 系统调用获取其退出状态。这是一种僵尸进程，通常由于父进程没有适当地处理子进程的退出状态而导致。

### I (Idle)

进程处于空闲状态，即没有可执行的任务，通常表示系统的空闲进程。

### W (Waiting)

进程正在等待某个事件的发生，但可以通过发送信号中断等待。这是在 `ps` 输出中的一种较旧的表示方式，较新的内核可能使用 `S` 代替。
