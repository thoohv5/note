```shell
1.使用excel 执行批量生成语句

set Login:18579081234 "123456" 
set Login:18579081235 "123456" 
set Login:18579081236 "123456" 

2.保存文件到服务器 （将步骤一内容保存到 redis.txt 文件中）

3.批量执行语句

cat redis.txt | redis-cli -c -h 127.0.0.1 -p 6389 -a 123 -n 1

参数详解。 -h 为服务的ip   -p 为redis 服务的端口  -a 为当前服务的密码  -n 为redis 服务的db
```
