# 安装

## **Red Hat/CentOS/Fedora 系（DNF/YUM包管理）**

```bash
# Fedora/CentOS 8+ 使用DNF：
sudo dnf install vim-enhanced

# CentOS 7及以下使用YUM：
sudo yum install vim-enhanced
```

## **Debian/Ubuntu 系（APT包管理）**

```bash
# 更新软件包列表（可选但推荐）
sudo apt update
# 安装Vim
sudo apt install vim
```

## **验证安装**

```bash
vim --version
```

## 编辑`~/.vimrc`文件，添加以下魔法：

```bash
set nu          "显示行号"
set tabstop=4   "Tab为4空格"
syntax on       "代码高亮"
colorscheme desert "护眼配色"
```
